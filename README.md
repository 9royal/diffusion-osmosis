# 擴散與滲透互動模擬器 v0.4.1

國中生物教學用的有限封閉雙區室互動模型，觀察水滲透、鹽擴散、膜通透性與動態平衡。採原生 HTML、CSS、JavaScript，不需資料庫、登入、金鑰或套件即可操作。

線上入口：https://diffusion-osmosis.dgejh-monster-115.workers.dev/

## 安裝與開啟
1. 下載此存放庫的 ZIP 並解壓縮，保留完整資料夾結構。
2. 直接開啟 index.html。若偏好本機 HTTP，先安裝 Node.js，再於專案資料夾執行 node scripts/serve.cjs，開啟終端顯示的本機網址。Windows 可雙擊 start-local.cmd。
3. 選擇教學情境，按「開始」，確認水與鹽的即時數量、圖表正常更新。

下載後可離線使用，沒有 Service Worker。重新下載新版時以完整資料夾取代舊版，重新整理瀏覽器確認版本。實驗不會跨分頁或重開後保存。

## 使用方式
- 選擇鹽擴散、水滲透、動態平衡、兩者皆可通或自由探索。水初始量 20–50，鹽 0–50；流動後某側庫存可超過 50，不截斷守恆量。
- 按「開始／暫停」、調整播放倍速；「重設」回到原始條件，「建立新實驗」解除設定鎖定。基礎模式開始後初始量與通透性鎖定。
- 水為圓形、鹽為菱形；四色記錄最初內外來源，跨膜後不變。水淡化與鹽淡化可獨立操作，粒子密度、顯示與淡化不改數值模型。
- 自由探索可切換膜通透性或人為轉移；物質及來源守恆，人為轉移與自然交換分帳。
- 四種圖表可按方向鍵或點擊查看歷史。即時庫存始終顯示當前值。

## v0.4.1 運動與溫度
粒子改為連續隨機轉向及碰壁反射，畫布按動畫幀更新，減少舊版短步互相抵銷造成的原地抖動觀感。低溫／常溫／高溫為定性示意，只調整區室內運動速度（係數 0.55／1／1.8），不改數值擴散、滲透速率、通透性或平衡。沒有攝氏或實際擴散係數校準；現實溫度效應亦受黏度與膜性質影響。播放倍速則控制整個實驗時間。

## 模型限制與常見問題
- 採充分混合、稀溶液及固定不可通背景溶質的理想化模型。鹽是單一電中性有效溶質，可通鹽不直接產生滲透驅動。
- 平衡時巨觀淨量可不變，但仍持續雙向交換。不可通的分子仍在自己的區室內運動；不能把不可通狀態稱作動態平衡。
- 跨膜動畫只使用數值模型批准的配額；代表粒子有取樣誤差與短暫延遲，請以數據區的量值為準。
- 暫停或關膜時會先補完已批准的跨膜動畫，不推進數值時間；完全暫停是播放功能，不代表真實分子停止。
- 不含膜電位、幫浦、靜水壓、膜張力或真實細胞體積調控。到安全體積邊界停止不等於平衡，亦不代表細胞真實破裂點。
- 模擬時間、分子數與溫度均未做真實物理校準。Safari、Firefox、真實手機及長時間教室操作尚未驗證。

## 檔案與測試
- index.html、styles.css、src/app.js：介面與圖表。
- src/model.js：數值模型；src/particles.js：粒子呈現；src/presentation.js：同步與干預。
- assets/：原始 Ro 品牌符號。
- tests/、scripts/：單元與瀏覽器驗證，輸出到 qa/（不提交）。

執行 node scripts/validate.cjs：49 項自動測試、語法與靜態檢查。選用瀏覽器測試需已有 Playwright；將 PLAYWRIGHT_MODULE 指向該套件，CHROME_PATH 指向 Chrome（若非預設位置），執行 tests/browser-smoke.cjs、browser-sync.cjs、browser-review.cjs、browser-clarity.cjs 與 browser-motion.cjs。本次本機 Chrome 的 43 組瀏覽器流程通過。
